# Рефакторинг сервиса заказов

Учебная работа по SOLID на Go. Сервис сохраняет заказ в SQLite и отправляет уведомление после успешной записи.

## Запуск

Нужен Go 1.26 или новее. Драйвер `modernc.org/sqlite` работает без CGO.

```sh
go run .
go test ./...
```

При запуске программа создаёт `orders.db` в текущей папке и добавляет два демонстрационных заказа. Email и SMS имитируются сообщениями в консоли.

## Устройство

- `internal/order` определяет модель заказа, сервис и его зависимости `RepositoryWriter` и `Notifier`.
- `internal/sqlite` создаёт таблицу и сохраняет заказы. Набор товаров сериализуется при записи в SQLite.
- `internal/notify` реализует общий метод `Send` для email и SMS.
- `main.go` собирает зависимости, инициализирует таблицу через отдельный интерфейс и запускает два примера с общим хранилищем.

Тест подменяет хранилище и отправителя и проверяет, что при ошибке записи число уведомлений остаётся равным нулю.
